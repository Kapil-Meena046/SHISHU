# SHISHU — an emotional anime archive

A standalone, responsive HTML/CSS/JavaScript fan archive. The intro uses the supplied `naruto.mp4` as a muted, looping, full-screen background. It is copied to `assets/naruto-intro.mp4`, so the original Downloads file is untouched.

## Open in VS Code

Open this `SHISHU` folder in VS Code. For local preview, open `index.html` directly or use the Live Server extension. No build step or dependencies are required.

## Edit the archive

- `data.js` contains the character, emotion, and episode data.
- `styles.css` contains the palette, typography, layout, and responsive rules.
- `script.js` handles intro playback, search, filters, and character/episode dialogs.
- Add more anime by adding character and episode entries to `SHISHU_DATA`.

The supplied clip informs the smoky charcoal, soft silver, and muted rose palette. This project uses no third-party anime images. The character cards use original abstract silhouettes and kanji accents instead.

Episode numbers are scoped to the series shown in each row. Filler / anime original and novel adaptation labels are identified in the archive. The featured episode list is intentionally curated rather than exhaustive. Episode title references were cross-checked against Crunchyroll's episode pages and episode-list references:

- [Crunchyroll — Naruto Shippuden episode 133: The Tale of Jiraiya the Gallant](https://www.crunchyroll.com/naruto-shippuden/episode-133-the-tale-of-jiraiya-the-gallant-534460)
- [Narutopedia — Itachi Shinden Book: Light and Darkness](https://naruto.fandom.com/wiki/Itachi_Shinden_Book:_Light_and_Darkness)
- [NarutoHQ — Naruto Shippuden episode list](https://www.narutohq.com/episodes/naruto-shippuden)
